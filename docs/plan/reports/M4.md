# M4 report: `rustible init` and `rustible playbook create`

**Branch:** `m4-init`. **Run:** unattended run 1, 2026-09-08. **Brief:** `docs/plan/M4.md`.
**Done-when log:** `docs/plan/logs/M4-done.txt`.

## What was built, per brief item

1. **`rustible init [dir]`** (`crates/rustible-cli/src/init.rs`, templates in
   `crates/rustible-cli/templates/`, embedded with `include_str!`). Refuses a
   non-empty directory unless `--force`. Writes `Cargo.toml` (package and bin
   name from the directory, `autobins = false`, `[features] selected = []`,
   `rustible` and `rustible-std` at the CLI's own `CARGO_PKG_VERSION`,
   `rustible-build` under `[build-dependencies]`, `[workspace]` to detach,
   `[profile.dist]`), the two shims `build.rs` and `src/main.rs` with the
   header from vision 9 (generated by `rustible init` at version X, do not
   edit, playbooks in `playbooks/`, shared code in `src/lib.rs`, regenerate
   with `rustible init --refresh`), `src/lib.rs` with a doc comment naming the
   crate identifier, `.cargo/config.toml` with the rust-lld musl linker config
   (M1 finding), `hosts.kdl` with a `local` host and a commented SSH host and
   group, `rustible.toml`, `playbooks/.gitkeep`, and `.gitignore` with
   `/target` and `/.rustible` (created, or the missing lines appended).
   `--refresh` rewrites only the two shims and requires `rustible.toml` and
   `Cargo.toml` to exist. No hash checking. Ends with a three-line "next"
   hint.
2. **`rustible playbook create <path>`** (`crates/rustible-cli/src/create.rs`).
   Writes a skeleton: doc line with the playbook name, `use
   rustible::prelude::*`, a commented `#[rustible::vars] struct Vars` with the
   two lines to change when enabling it, `#[rustible::playbook(hosts =
   "local")]` on a `main` with one `ctx.log`. Creates directories, refuses to
   overwrite, derives the name from the path under the workspace's
   `playbooks/` (found by walking up to `rustible.toml`, vision 10.4), then
   prints the check-on-save hint from vision 9.
3. **Regeneration test** (`crates/rustible-cli/tests/init.rs`,
   `regenerates_the_example_workspace`). Runs the built binary with
   `--path-deps ../..` into a temp dir laid out like the repository and
   asserts `Cargo.toml`, `build.rs`, `src/main.rs` and `.cargo/config.toml`
   equal `examples/workspace` byte for byte. Six more integration tests cover
   the non-empty refusal and `--force`, the `.git`-only directory and
   `.gitignore` append, crates.io versions and name sanitization, `--refresh`
   touching only the shims, `--path-deps` validation, and `playbook create`
   (skeleton, hint, refusal, `.rs` completion, outside-`playbooks/` warning).
   Nine unit tests cover the pure functions.
4. **`--path-deps <checkout>`** writes `{ path = "<checkout>/crates/<crate>" }`
   for the three crates, after checking the three manifests exist.

**CLI shape.** `main.rs` now has `run` (the spike orchestrator, flags
unchanged), `init`, and `playbook create` as clap subcommands; the orchestrator
body moved into `async fn run(RunArgs)` untouched. The M2 branch adds
`inventory` next to these.

**`examples/workspace`** was regenerated with the tool. The shims and
`.cargo/config.toml` were already identical. `Cargo.toml`'s two comments,
`rustible.toml`'s comment and `.gitignore` (now with `/.rustible`) took the
generated wording; `src/lib.rs`, `hosts.kdl` and `playbooks/` keep their
example content (`hello.rs` uses `workspace::greeting`, M3's done-when needs
the `lab` group).

## Verified

`docs/plan/logs/M4-done.txt`: the brief's done-when block with the built
binary standing in for an installed `rustible`. `init /tmp/rx --path-deps
$PWD` writes nine files; `playbook create playbooks/hello.rs` writes the
skeleton and prints the hint; the generated workspace builds and `cargo run --
hello` runs the playbook against `local` (`--describe` lists it); `git init -q
&& rustible init --refresh && git status --short` rewrites the two shims (with
a commit in place, the status is empty after a refresh, and empty again after
hand-editing both shims and refreshing, so only the shims are touched). Also
in the log: the crates.io dependency form, the three refusals, and `cargo fmt
--check`, clippy `-D warnings`, `cargo test --workspace` on the branch.

## Deviations

- **`rustible playbook run playbooks/hello.rs` is not runnable until M3.** The
  log shows the verbatim command failing with "unrecognized subcommand" and
  then `cargo run -- hello` inside the generated workspace, as the lead
  instructed. The generated `init` hint still names `rustible playbook run`
  because that is the M3 command.
- **`.gitignore` lines are `/target` and `/.rustible`**, the example's
  root-anchored form, not the brief's `target/` and `.rustible/`.
- **`hosts.kdl`'s example lines are comments** (an SSH host and a group) plus
  the live `local` host; the example workspace's `lab` group with the ARM VM
  is not generated.
- **`--name` was added** (not in the brief) as the way out of the reserved-name
  error; see Decisions.
- **Version bumps require `rustible init --refresh examples/workspace`**
  because the regeneration test is strict about the shim headers; the test's
  failure message says so.

## Decisions

Recorded in `docs/plan/DECISIONS.md` under rule 2.3: `.git`-only directories
count as empty; `--name` and the reserved-name list; `.gitignore` anchored
lines and append-whenever-present; `--path-deps` written as given and
validated; the strict regeneration test; `playbook create`'s `.rs`
completion, overwrite refusal and outside-`playbooks/` warning.
