# M4: `rustible init` and `rustible playbook create`

**Governing sections:** 3, 9 (shims, `selected` feature, `rustible-build`), 10.4.
**Depends on:** M1 (the shim contents exist in `examples/workspace`).
**Branch:** `m4-init`

## Scope

1. `rustible init [dir]`: refuses a non-empty directory unless `--force`;
   writes `Cargo.toml` (package name from the directory, one bin,
   `autobins = false`, `[features] selected = []`, `[dependencies] rustible,
   rustible-std` at the CLI's own version, `[build-dependencies]
   rustible-build`), `build.rs` and `src/main.rs` as the two-line shims with
   the header comment (generated by version X, do not edit, playbooks in
   `playbooks/`, shared code in `src/lib.rs`, regenerate with
   `rustible init --refresh`), `src/lib.rs` with a doc comment, `playbooks/.gitkeep`,
   `hosts.kdl` with a commented example (a `local` host), `rustible.toml`, and
   `.gitignore` entries `target/` and `.rustible/` (created, or appended when
   inside a git repository and a `.gitignore` exists). `--refresh` rewrites only
   the two shims. No hash checking (vision 9).
2. `rustible playbook create <path>`: writes a playbook skeleton (attribute
   with `hosts = "local"`, a `Vars` struct commented out, a `main` with one
   `ctx.log`), creating directories as needed; prints the check-on-save hint
   from vision 9.
3. `examples/workspace/` is regenerated by `init` in a test to prove the two
   stay identical (the example is the reference; the generator is tested
   against it).
4. `--path-deps <rustible checkout>` flag (development only) that writes path
   dependencies instead of versions, so the dogfooding workspace inside
   `my_infra` can use the local checkout.

## Out of scope / do not touch
The SDK, the macros, the pipeline.

## Done when
```
rustible init /tmp/rx --path-deps $PWD && cd /tmp/rx
rustible playbook create playbooks/hello.rs
rustible playbook run playbooks/hello.rs          # local host from the generated hosts.kdl
git init -q && rustible init --refresh && git status --short   # only the two shims touched
```
