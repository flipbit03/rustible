# M7: Release 0.1.0

**Governing sections:** 9 (publishing), 3.
**Depends on:** M1 to M6 merged; D at least step 3 done by a human.
**Branch:** `m7-release`

1. README rewrite: what it is, install (`cargo install rustible-cli`), a
   five-minute tutorial (init, create, hosts.kdl, run, check mode), the op
   list, how to write a collection.
2. rustdoc on every public item; `cargo doc --no-deps` warning-free.
3. `.github/workflows/ci.yml`: fmt, clippy `-D warnings`, test, the Docker
   harness on Linux.
4. `.github/workflows/release.yml` modeled on flipbit03/terminal-use: on a
   published release tagged `vX.Y.Z`, patch the workspace version, publish the
   seven crates in dependency order (`rustible-sdk`, `rustible-macros`,
   `rustible-build`, `rustible-std`, `rustible-github`, `rustible`,
   `rustible-cli`) with index-lag retries, build `rustible-cli` for
   `x86_64-unknown-linux-musl` and `aarch64-unknown-linux-musl` (and macOS
   aarch64 for the CLI only; targets remain Linux-only), upload the binaries
   to the release. Uses the `CARGO_REGISTRY_TOKEN` secret.
5. **Publishing itself is not done unattended.** The workflow is written and
   tested with a dry run; the release is cut by Cadu.
