## `rustible-github`
`github::UserKeys::of("user")`: read-only op, `ureq` + rustls, returns
`Vec<PublicKey>`; a helper `github::keys_to_user(ctx, gh_user, sys_user)` that
composes it with `authorized_keys::Present`. Own crate, depends on
`rustible-sdk` and `rustible-std` only.

## Docker harness
`rustible-sdk::testing::integration` with a `#[rustible::integration_test(images = [...])]`
attribute (in `rustible-macros`) that builds the test binary for musl and runs
it in each image with `docker run`, asserting changed-then-ok. Images:
`debian:12`, `ubuntu:24.04`. Runs in CI when docker is available, skipped
otherwise. Also a `SystemdImage` variant for the systemd ops (a systemd-enabled
image; document which).

## Done when
Every op above has pure tests, `Fake` tests (satisfied, change, apply, failure,
wrong distro where applicable), rustdoc naming the Ansible equivalent, and a
harness test; `cargo test -p rustible-std` and `cargo test -p rustible-github`
pass; the harness passes on both images.
