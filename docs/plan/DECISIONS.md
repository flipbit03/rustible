# Decisions made without a human

Entries added by unattended runs under docs/07_UNATTENDED.md rule 2.3.
Format: `- [M<n>] <date> <decision>: <why>; <how to reverse>`.
Cadu reviews these; a decision he rejects is reversed in a follow-up task and
the vision doc is amended if the question deserved a real answer.
- [M1] 2026-09-08 `rustible init` must generate `[profile.dist]` and `.cargo/config.toml` (rust-lld per musl target) in every workspace: a detached workspace inherits neither from the repo; found when the orchestrator's dist build failed against `examples/workspace`. Reverse: none needed, this is a gap in the M4 brief, not a design change.
- [M1] 2026-09-08 `#[rustible::vars]` rejects maps and tuples syntactically; nested structs cannot be told from enums in a proc macro, so the orchestrator's vars validation (M2/M3) must reject schema properties of `type: object`. Reverse: add a `#[vars]`-side check if a reliable syntactic rule appears.
- [M1] 2026-09-08 `--var k=v` parses `v` as JSON when it parses, else as a string (numbers, bools, lists work without quoting). Reverse: make it string-only and require typed syntax.
- [M1] 2026-09-08 Vars deserialization does NOT use `deny_unknown_fields`: the host var bag is shared by all playbooks targeting the host (vision 10.3), so undeclared keys are legitimate; the runtime warns per undeclared key with a did-you-mean instead. Reverse: add `deny_unknown_fields` in the `#[vars]` expansion.
- [M1] 2026-09-08 Alternating `rustible playbook run` between two playbooks re-links the bin each time (one `selected` OUT_DIR, `rerun-if-env-changed`). Observation for M3: weigh a per-playbook artifact cache keyed by (playbook, triple, source hash) against duplicated dependency artifacts. Reverse: n/a, nothing built.
- [M1] 2026-09-08 `rust-version` raised from 1.85 to 1.88 because the code uses let-chains (stable in 1.88, edition 2024). Reverse: nest the `if let`s.
- [M1] 2026-09-08 Vars flatness is enforced on the generated JSON Schema (`vars::flatness_violations`, resolving `$ref`s) at `--describe` and at `Start`; the macro's syntactic map/tuple rejection is only an early hint. Supersedes the earlier M1 note that deferred this to M2/M3.
- [M5] 2026-09-08 The escalation method reaches the binary as `HostInfo.escalate_method` (serde default `sudo`), not as a new `Start` field: `HostInfo` already carries `escalate_user` and vision 11.1 makes it the home of target-relevant parameters. Reverse: move the field to `Start`.
- [M5] 2026-09-08 Byte fields on the wire (`FileChunk`, `FetchChunk`, helper frames, `CmdSpec.stdin`, `Output`) are base64 strings via the `base64` crate, not JSON number arrays (3.5x the payload for a 50 MB file over SSH). Frame bodies are zeroized after decoding. Reverse: drop the `#[serde(with = "b64")]` attributes.
- [M5] 2026-09-08 EOF on stdin in `--remote` mode cancels the run (reason "the orchestrator closed the channel"): with the orchestrator gone nobody receives the report, so stopping between steps beats a blind run. Reverse: make `Feeder::close` only close the inbox.
- [M5] 2026-09-08 `ctx.fetch(remote, "out/")` (trailing slash) lands at `out/<host name>/<file name>` so several hosts do not overwrite each other, as Ansible's `fetch` does; a destination without a trailing slash is used verbatim. Reverse: drop the host segment.
- [M5] 2026-09-08 `ctx.fetch` reads the remote file through `sys.read` in one piece (so an escalated `Ctx` fetches what its identity can read) and chunks it afterwards; the helper frame limit caps an escalated fetch at 64 MiB. Reverse: add a streaming read primitive to `Backend`.
- [M5] 2026-09-08 An escalation password is fed to `sudo -S` only after `sudo -n -u <user> true` was refused: on NOPASSWD hosts `sudo -S` leaves the unread password line on the request pipe and corrupts framing. `doas` with a password is an error (no stdin option). Reverse: always use `-S` when a password is present.
- [M5] 2026-09-08 `System::as_user` on a `Fake` system keeps the `sudo -n -u <user>` command prefix (no helper exists to spawn); on a real system the prefix is empty because the helper already is that user. Reverse: add an `elevate` hook to `Backend`.
- [M5] 2026-09-08 The spike CLI's SSH transport uses openssh's `native-mux` feature (pure Rust `openssh-mux-client`) and local children start in their own process group: otherwise ctrl-c kills the per-command `ssh` client or the local binary before `Cancel` can be sent. Reverse: `process-mux` plus EOF-as-cancel on the binary side.
- [M5] 2026-09-08 Killing a remote binary after the cancel grace matches every process whose command line names the binary's cached path, plus their children; a concurrent run of the same playbook build on the same host would be killed too. Reverse: have the binary report its pid in `Hello`.
- [M5] 2026-09-08 A local run (no `--remote`) serves `local_file` from the working directory under the orchestrator's rules, so a playbook developed locally sees the same denials. Reverse: `Channel::detached()` in local mode.
- [M5] 2026-09-08 `Cancel` between `check` and `apply` fails the step (`StepFinished { Failed, note: "cancelled..." }`) rather than reporting `WouldChange`: the check ran but nothing was applied, and a plain failure is the honest status. Reverse: report `Skipped`.
